# spring-boot-gym

A structured Spring Boot / Java backend practice, built lesson by lesson.

## Structure
- `modules/` - code for each module
- `docs/` - concept notes and comprehension-check write-ups, per module

## Modules
1. Spring Fundamentals
2. REST APIs
3. Data JPA
4. Validation & Error Handling
5. Security
6. Testing
7. Capstone Project (fintech accounts/transactions API)
